# Capture provenance

These are actual captures from the current engine running
`examples/RenderingShowcase/Showcase.myproject` on Windows with OpenGL.

- `editor.png`: docked editor, scene hierarchy, viewport and content browser.
- `materials.png`: the same example in the standalone renderer.

All meshes are generated by the example's standard-library Python script.
The scene contains no assets, interface or source from a separate game project.
PNG recompression preserves the original rendered pixels.
